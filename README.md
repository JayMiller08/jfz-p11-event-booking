# P11 · Event Booking System

Book and cancel seats in a venue grid with custom exceptions, behind a menu that survives anything a user types.

https://www.jaymthethwa.co.za/java/projects/event-booking-system

## Run the tests

- **IntelliJ IDEA:** open `src/test/java/jfz/booking/BookingTest.java` and click the green ▶
  next to `class BookingTest`.
- **Terminal (macOS/Linux):** `./mvnw test`
- **Terminal (Windows):** `mvnw.cmd test` (in PowerShell: `.\mvnw.cmd test`)

The first run downloads what it needs, so give it a minute. Push your work and
GitHub runs the same tests. A green tick means you passed.

To try the box office yourself, run `src/main/java/jfz/booking/BookingApp.java`.
